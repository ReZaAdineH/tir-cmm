# TIR-CMM Machine-Readable Public Model

The canonical TIR-CMM website publishes machine-readable integration artifacts under **CC BY 4.0**.

Current canonical model version: **0.2**.

## Canonical artifacts

- JSON model: https://tir-cmm.com/data/tir-cmm-model.json
- YAML model: https://tir-cmm.com/data/tir-cmm-model.yaml

The JSON/YAML model describes the published domains, sub-capabilities, maturity levels, Containment Lattice, constraints and related integration metadata.

## Repository policy

These files should only be mirrored into this repository when they can be transferred from the canonical source without reconstruction or semantic editing. That protects model fidelity and prevents a GitHub copy from silently diverging from the public API.

Until an exact mirrored copy is present, the canonical URLs above are the authoritative machine-readable source.

Do not substitute the source-available assessment-tool implementation for these openly licensed model artifacts.
