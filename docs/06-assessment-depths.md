# TIR-CMM Assessment Depths

Version 0.2 introduced the three assessment depths retained by v1.0. Each is a strict superset of the one below, so organisations can deepen an assessment without changing the underlying model.

## Pulse

- about **20 minutes**;
- **20 questions**;
- no Containment Lattice;
- no ATT&CK dependency;
- no evidence review;
- reported band capped at **L3**;
- intended as an indicative starting point.

Pulse answers: **Where do we stand, roughly?**

## Baseline

- about **1–2 hours**;
- all **58 sub-capabilities**;
- evidence levels;
- crown-jewel-scoped Containment Lattice;
- authority map;
- response tempo;
- reported band capped at **L4**;
- self-service, but suitable for leadership planning when caveats are stated.

Baseline answers: **What can we prove from the evidence we have?**

## Assurance

- approximately **2–4 weeks**;
- Baseline plus telemetry attributes by asset class;
- exercised scenarios with observed timings;
- governance and calibration layer;
- independent evidence-led review;
- no assessment-depth ceiling.

Assurance answers: **Can we stand behind the result under challenge?**

A tier ceiling is not a penalty. The depth of the assessment is evidence about how far its conclusions can legitimately travel.
