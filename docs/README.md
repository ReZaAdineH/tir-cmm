# TIR-CMM Public Knowledge Base

Canonical website: https://tir-cmm.com

Canonical version history: **v0.2 · published 17 August 2026** according to the TIR-CMM changelog and About page.

TIR-CMM — the Threat-Informed Response Capability Maturity Model — measures whether an organisation can act on what it detects inside the adversary's breakout window, with sufficient authority, at an acceptable blast radius, and with evidence that the capability works.

## Canonical architecture relationship

UTIOM is the foundation and remains the operating model. TIR-CMM is a response measurement module within the capabilities UTIOM already defines. TID-CMM is the detection measurement companion.

TIR-CMM deliberately contains no detection domain. It consumes detection maturity as a constraint.

When a website footer/header label conflicts with the explicit TIR-CMM changelog/version-history page, this repository follows the changelog/version-history statement rather than inventing a reconciliation.
