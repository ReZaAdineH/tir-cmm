# TIR-CMM Community

TIR-CMM v1.0 is published for practitioner validation. The community exists to improve the response maturity instrument through real evidence, measured response data, counter-examples and transparent discussion.

## High-value contributions

- a constraint that fired where it should not have, or failed to fire where it clearly should;
- a Containment Lattice cell that could not be scored honestly;
- an asset class or attack-path stage the lattice cannot express;
- measured MTTDecide, MTTC or Containment Margin data;
- a response engineered-versus-proven gap that contradicts the model's assumptions;
- evidence from standalone TIR-CMM use that helps calibrate the prerequisite check;
- OT/ICS or cloud/SaaS response cases that expose a modelling weakness;
- standards/crosswalk corrections;
- implementation stories, assessment lessons and anonymised evidence.

## Discussions versus Issues

Use **Discussions** for questions, implementation stories, research, interpretation, early ideas and debate.

Use **Issues** for concrete model defects, constraint challenges, lattice problems, mapping corrections and scoped documentation changes.

Security findings must be reported privately under `SECURITY.md`.

## Governance

Community participation does not silently rewrite TIR-CMM. Changes that affect scoring, constraints, domain structure, lattice semantics, evidence ceilings or version interpretation require explicit maintainer review and changelog/version treatment.

UTIOM remains the overarching operating model. TIR-CMM remains the response measurement module. TID-CMM remains the detection measurement companion.

## Quarterly response-model review

Community review should group evidence into:

1. constraint calibration;
2. lattice structure and scoping;
3. response-tempo evidence;
4. authority and decision-rights findings;
5. exercising/validation evidence;
6. standards and regulatory mappings;
7. assessment-depth/governance calibration;
8. documentation and usability.

The goal is not endorsement. It is a stronger instrument that survives contact with real response operations.
