# TIR-CMM Public Integration Schemas

The canonical TIR-CMM site publishes integration schemas under **CC BY 4.0**.

## Canonical schemas

- TIR-CMM assessment export schema: https://tir-cmm.com/schemas/tir-cmm-export.schema.json
- TID-CMM import schema: https://tir-cmm.com/schemas/tid-cmm-import.schema.json

These schemas define the public integration contracts used to exchange TIR-CMM assessment data and to consume TID-CMM detection-maturity input without merging the two models.

## Fidelity rule

A future local mirror should be copied exactly from the canonical site. Do not reconstruct or broaden the schemas from prose because that could create an incompatible integration contract.

The existence of open schemas does not make the assessment-tool implementation open source.
